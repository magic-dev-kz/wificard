# WiFi Card — Product Spec
**Product #10 | OpenClaw Sandbox**
**Date:** 2026-03-29
**Author:** Саня (Product Manager)

---

## 1. Название

**WifiCard** (wificard.app)

Альтернативы: WifiPass, ScanConnect, QRFi Card

---

## 2. One-liner

Красивая WiFi-карточка с QR-кодом за 5 секунд. Для Airbnb, кафе и дома. Бесплатно, офлайн, без регистрации.

---

## 3. Persona

**Марина, 34 года** — хозяйка двух квартир на Airbnb в Тбилиси.

- Каждый новый гость спрашивает WiFi пароль
- Написала пароль на бумажке, но выглядит непрофессионально
- Пробовала Canva — слишком сложно ради одной карточки
- Нашла шаблон на Etsy за $5, но не смогла вставить QR-код
- Хочет: ввести SSID + пароль -> получить красивую карточку -> распечатать

**Также подходит:** владельцы кафе, отелей, коворкингов, домашние пользователи, офис-менеджеры.

---

## 4. Главная функция (одна)

**Генерация готовой к печати WiFi-карточки с QR-кодом.**

Не голый QR-код, а карточка с:
- QR-кодом для автоматического подключения к WiFi
- Названием сети (SSID)
- Паролем (опционально, можно скрыть)
- Красивым дизайном из шаблона
- Иконкой WiFi

---

## 5. Изюм (чем отличаемся)

| Конкурент | Что делает | Чего не хватает |
|-----------|-----------|-----------------|
| QiFi.org | Генерирует WiFi QR | Уродливый, только голый QR, нет шаблонов |
| QR Tiger | WiFi QR + кастомизация | Paywall, отправка данных на сервер |
| Etsy шаблоны | Красивый дизайн | $3-10, нужна Canva, нет QR-генерации |

**WifiCard = QiFi + Etsy в одном.** Красивая карточка + QR-генерация + офлайн + бесплатно.

### Конкретный изюм:
1. **6 дизайнерских шаблонов** — выбрал стиль, готово
2. **Мгновенный предпросмотр** — карточка обновляется в реальном времени
3. **Печать одним кликом** — кнопка Print, оптимизировано для принтера
4. **100% офлайн** — пароль НЕ отправляется никуда (security selling point)
5. **Скачать как PNG** — для отправки в чат или типографию

## 7. User Flow

```
[Открыл страницу]
     |
     v
[Видит форму: SSID + Password + Encryption]
[Справа/снизу: предпросмотр карточки в реальном времени]
     |
     v
[Вводит данные — карточка обновляется МГНОВЕННО]
     |
     v
[Выбирает шаблон (6 вариантов в виде превью)]
     |
     v
[Опционально: показать/скрыть пароль на карточке]
     |
     v
[Кнопка "Print" или "Download PNG"]
     |
     v
[ГОТОВО — карточку можно повесить в квартире/кафе]
```

**Время от открытия до результата: < 30 секунд.**

## 8. Acceptance Criteria

### AC-1: Генерация WiFi QR-кода
- Пользователь вводит SSID, пароль, тип шифрования (WPA/WPA2/WPA3, WEP, None)
- QR-код генерируется на клиенте в реальном времени при вводе
- QR-код содержит валидную строку формата `WIFI:T:WPA;S:name;P:pass;H:false;;`
- При сканировании QR-кода телефон предлагает подключиться к сети

### AC-2: Шаблоны карточек
- Доступно минимум 6 шаблонов карточек
- Каждый шаблон визуально отличается (цвета, шрифты, стиль)
- Переключение между шаблонами мгновенное (без перезагрузки)
- Карточка содержит: QR-код, иконку WiFi, SSID, пароль (опционально)

### AC-3: Предпросмотр в реальном времени
- Карточка обновляется при каждом нажатии клавиши (debounce 150ms)
- QR-код перегенерируется при изменении любого поля
- Пустое поле SSID -> карточка показывает placeholder

### AC-4: Печать
- Кнопка "Print" вызывает window.print()
- Print CSS: только карточка, без UI формы
- Карточка оптимизирована для формата ~10x7 см (визитка/стойка)

### AC-5: Скачивание PNG
- Кнопка "Download" сохраняет карточку как PNG (через Canvas API)
- Разрешение: минимум 600x400px (достаточно для печати)
- Имя файла: `wifi-card-{SSID}.png`

### AC-6: Переключатель видимости пароля
- Чекбокс "Show password on card" (по умолчанию: включён)
- Когда выключен: пароль заменяется на "Scan QR to connect"
- На форме пароль всегда виден (input type=text)

### AC-7: Скрытая сеть
- Чекбокс "Hidden network"
- Если включён: в QR добавляется `H:true`
- На карточке появляется пометка "(Hidden network)"

### AC-8: Офлайн-работа
- Приложение работает без интернета после первой загрузки
- Никакие данные не отправляются на сервер
- Вся генерация QR происходит на клиенте
- Явное сообщение: "Your password never leaves your browser"

### AC-9: Responsive дизайн
- Desktop: форма слева, предпросмотр справа (side by side)
- Mobile: форма сверху, предпросмотр снизу
- Карточка масштабируется корректно на всех размерах экрана
- Touch-friendly элементы управления

### AC-10: Мгновенная ценность
- Страница загружается < 1 секунды
- Placeholder данные при первой загрузке (SSID: "MyWiFi", Password: "password123")
- Пользователь СРАЗУ видит пример карточки ещё до ввода данных

## 9. Технические требования

### Стек
- **Один файл `index.html`** — HTML + CSS + JS
- **Vanilla JS** — без фреймворков
- **QR-библиотека:** встроенный QR encoder (взять код из qr-creator или qrcodejs, заинлайнить)
- **Canvas API** — для экспорта в PNG
- **CSS Print Media Query** — для печати

### QR-генерация
- WiFi QR строка: `WIFI:T:{type};S:{ssid};P:{password};H:{hidden};;`
- Спецсимволы экранируются: `\`, `;`, `,`, `"`, `:`
- QR рендерится в `<canvas>` элемент
- Error correction level: M (15%)

### Шаблоны
- Каждый шаблон = CSS-класс на контейнере карточки
- HTML-структура карточки одна, стиль меняется через класс
- Шрифты: системные (без загрузки внешних) или встроенные через base64

### Производительность
- Весь файл < 100KB
- Нет внешних запросов (кроме опционально шрифтов)
- First Contentful Paint < 500ms

## 10. Anti-scope (что НЕ делаем)

1. **НЕ** dynamic QR-коды (нет сервера, нет аналитики)
2. **НЕ** сканер QR-кодов (только генератор)
3. **НЕ** другие типы QR (только WiFi)
4. **НЕ** пользовательские аккаунты / регистрация
5. **НЕ** сохранение истории QR-кодов в облаке
6. **НЕ** API для интеграции
7. **НЕ** кастомизация цветов QR-кода (делаем стильно из коробки)
8. **НЕ** логотип внутри QR (усложняет, снижает надёжность сканирования)
9. **НЕ** мультиязычность (v1 на английском)
10. **НЕ** PWA/Service Worker (v1 — просто HTML файл)

---

## 11. Share-момент

**"Scan to connect"** — карточка сама по себе является share-моментом.

Пользователь печатает карточку и ставит на стол / вешает на стену. Каждый гость, который сканирует QR, видит красивый дизайн. Это виральность через физический мир.

Дополнительно: кнопка "Share" для отправки PNG через мессенджер (Web Share API, если доступен).

## 12. Метрики успеха

- **Время до первого результата:** < 30 секунд
- **Количество кликов до печати:** максимум 4 (ввод SSID, ввод пароля, выбор шаблона, Print)
- **Размер файла:** < 100KB
- **Lighthouse Performance:** > 95
